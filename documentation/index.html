Custom Affiliate Link Manager

Welcome to the documentation for Custom Affiliate Link Manager. This guide will help you install, configure, and use the plugin effectively.

1. Introduction

Custom Affiliate Link Manager is a professional WordPress plugin designed to help you manage, cloak, and track your affiliate links. It provides a clean interface to create "pretty links" that are easy to share and track.

2. Installation

  1. Download the plugin ZIP file.
  2. Log in to your WordPress admin dashboard.
  3. Go to Plugins > Add New.
  4. Click Upload Plugin and select the ZIP file.
  5. Click Install Now and then Activate.

3. Getting Started

Creating Your First Link

To create a new affiliate link:

  1. Go to Affiliate Links > Add New.
  2. Enter a Title for your link (e.g., "My Favorite Product").
  3. In the Affiliate Link Settings meta box, enter the Target URL.
  4. Choose the Redirection Type (301 is recommended for SEO).
  5. Click Publish.

Your "pretty link" will be automatically generated based on the title. You can customize the slug in the permalink settings.

4. Advanced Features

Geo-Targeting

Redirect users to different URLs based on their country. This is useful if you have different affiliate links for different regions (e.g., Amazon US vs. Amazon UK).

A/B Testing

Split traffic between multiple target URLs to see which one performs better. You can set the percentage of traffic for each URL.

Link Health Check

Go to Affiliate Links > Health Check to verify if your target URLs are still active. The plugin will check the response codes and alert you to any broken links.

5. Shortcodes

You can insert your affiliate links into posts or pages using the [affiliate_link] shortcode.

[affiliate_link slug="my-product" text="Buy Now"]

Parameters:

  • id: The ID of the affiliate link post.
  • slug: The slug of the affiliate link.
  • text: The text to display for the link.
  • class: Custom CSS class for the link.
  • target: Link target (e.g., _blank).
Note: Always ensure you are following the terms of service of your affiliate programs when using link cloaking.
